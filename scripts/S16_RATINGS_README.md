# S16 世界赛卡 · 出局定格说明

站长 2026-10-10 的规则：**战队还在比赛时，这支队五个人的卡都是「?」；战队被淘汰的那一刻，五个人的最终数值、金银铜、八项属性一起揭晓，并永久定格**（以后普通卡怎么调都不再变）。入围赛出局的最先揭晓，冠亚军决赛后最后揭晓。

世界赛期间（2026-10-15 → 11-14）**每个有队出局的比赛日**做一次，5 分钟左右。没有队出局的日子什么都不用做。

## 0. 只做一次：导出普通卡底分

```
npx tsx scripts/s16_base_export.ts
```

生成 `scripts/s16_base.json`（名单上每个人的普通卡评分和八项属性）。**名单（`src/data/s16.json`）改过（比如补登替补）要重跑一次**。普通卡数值后来又调了也可以重跑——已经定格的卡不受影响，只有还没出局的队会用新的底分。

## 1. 登记出局的队

打开 `src/data/s16Results.json`，在 `teams` 里每支出局的队加一行（俱乐部 id 见 `src/data/s16.json` 的 `teams[].club`）：

```json
 "teams": {
  "T49": { "placement": "playin", "out": "2026-10-17" },
  "T35": { "placement": "swiss",  "out": "2026-10-26" },
  "T20": { "placement": "qf",     "out": "2026-11-04" }
 }
```

| placement | 意思 | 档中心 / 封顶 |
|---|---|---|
| `playin` | 入围赛出局 | 68 / 74 |
| `swiss` | 瑞士轮出局（0-3、1-3、2-3 都是） | 75 / 82 |
| `qf` | 八强 | 79 / 86 |
| `sf` | 四强 | 82 / 88 |
| `runnerup` | 亚军 | 84 / 89 |
| `champion` | 冠军 | 86 / 90 |

`out` = 出局那天（北京时间）。`stages` 是各阶段日期（已经按官方赛程填好，淘汰赛 ×1.5、决赛 ×2 的权重用），一般不用改。

## 3. 跑一条命令

在仓库根目录（`game` 或 worktree 目录）下：

```
python scripts/s16_ratings.py --oe "../../lol选手/data/oracleselixir/2026_OE.csv" --dry-run
```

看一眼输出，没问题就去掉 `--dry-run` 再跑一次，写进 `src/data/s16Ratings.json`。

| 输出 | 要做什么 |
|---|---|
| 「X 局，Y 个比赛日（最后一天 …）」 | 最后一天要 ≥ 刚登记的出局日 |
| 「对不上名单的世界赛选手」 | 替补上场了（名单补人后重跑第 0 步），或者名字拼法不同（在脚本顶部 `ALIASES` 加一行 `"oe里的名字小写去空格": "名单里的ign"`） |
| 「名字对上了、队伍对不上」 | 同名的另一个人或者换队了，人工确认 |
| 「先不定格」 | OE 还没到出局那天，等更新 |
| 「这次新定格：…」+ 表格 | 每人：局数、有效局数（按对手强度加权后）、普通卡、表现分、档中心、S16 评分、箭头、金银铜 |

**已经定格的卡，脚本永远原样保留**，重跑多少次都不会变。登记错了才需要：

- `--refreeze T35`：按现在的登记重新算这支队（比如名次填错了）。
- `--unfreeze T35`：撤销定格，卡面回到「?」（比如把还在比赛的队误登记成出局）。

**决赛后最后一次**：登记冠亚军（`runnerup` / `champion`，`out` 都是 11-14），加上 FMVP：

```
python scripts/s16_ratings.py --oe "../../lol选手/data/oracleselixir/2026_OE.csv" --final --fmvp Chovy --fmvp-rating 96
```

`--final` 会核对 19 支队都登记了名次；`--fmvp` 填 ign（大小写要和名单一致，必须是冠军或亚军队的人），他的卡变成彩卡，评分按 `--fmvp-rating`（94–97，不填 95）。之后再跑不用重复写 `--fmvp`，会沿用。

## 算法

**S16 评分 = 档中心 + 0.6 ×（普通卡评分 + 表现分（±6） − 80）**，四舍五入，夹在 [50, 档封顶]。一局没上的替补表现按 0，和队友同一档。

站长 2026-10-19：先出局的队要给后面的队、给冠军留空间——冠军 90 上下，75–90 留给走得远的队，入围赛出局最高 74。所以按名次分档（上面的表），同一档里再按普通卡和表现排：普通卡或表现差 1 分，S16 差 0.6 分（`SPREAD`），普通卡 80、表现 0 的人正好落在档中心（`BAND_PIVOT`）。

1. **底分**：他的普通卡评分（`s16_base.json`），把整体尺度定住。
2. **单局表现**：每局和**对面同位置的人**比八项，都是「我 − 对面」：15 分钟经济差、经验差、补刀差，伤害占比差，参团率差，死亡差（对面 − 我），分均视野差，经济占比差。每项除以它在 2025 年 LCK/LEC/LTA/LCP/MSI/世界赛 1752 局里的标准差（`SCALES`，写死，先出局和后出局的队用同一把尺子），截在 ±3，按位置加权（辅助看参团/视野/少死，上中下看对线和伤害，`WEIGHTS`），再除以合成后的标准差（`INDEX_SD`）→ 单局表现，标准差 1。
3. **扣掉本来就该有的优势**：他的普通卡比对位高 1 分，单局表现「本来就该」高 0.03（`EXPECT_PER_PT`，2025 世界赛 840 个对位的回归斜率）。Chovy 打赢一个 72 分的中单不算本事。
4. **对手越强越算数**：每局权重 = (对手全队普通卡均值 − 72) / 12，夹在 0.10–1.25：对手均值 84 记 1 局，78 记半局，72 以下记 0.1 局。淘汰赛再 ×1.5，决赛 ×2。入围赛打弱队刷出来的数据几乎不算。
5. **收缩**：表现分 = 10 × Σ(权重 × (单局表现 − 应有优势)) / (Σ权重 + 5)，夹在 ±6。相当于先放 5 局「表现 0」的满权重对局：有效局数 5 → 可信度一半，20 → 80%。
6. **名次分档**（`PLACEMENT_BAND`）：档中心 入围赛 68、瑞士轮 75、八强 79、四强 82、亚军 84、冠军 86；封顶 74 / 82 / 86 / 88 / 89 / 90。同样的普通卡和表现，走得越远分越高；入围赛出局的再强也到不了 75。
7. **金银铜**：和普通卡同一条线（`src/engine/cards.ts` 的 `GOLD_AT` 84 金、`SILVER_AT` 72 银），不按名次——先揭晓的队不会被后面的结果改档。
8. **箭头**：`prev` = 普通卡评分，卡面「90 ▲4」= 比他的普通卡高 4。
9. **八项属性** = 普通卡属性 + (S16 评分 − 普通卡评分)，夹在 1–99。

常数都在 `s16_ratings.py` 顶部 `tunables` 一节。2025 世界赛（S15）回测和调参过程：`../S16世界赛系列/backtest_2025_新算法.md`；回测用的名单、底分、出局登记和结果在 `../S16世界赛系列/backtest_2025_新算法/`，可以用同一个脚本复跑（`--base/--roster/--results/--out` 指过去，`--year 2025`）。
