# 手机体验整改与验收（2026-09-21）

## 第一轮策划
目标：挑战能可靠显示，失败可恢复；窄屏内容和操作不被裁切。
1. 修正挑战图片实际格式与 HTTP MIME / 匿名文件名的一致性，保留防泄题接口。
2. 挑战加载增加超时、取消、重试、明确状态；图片未绘制成功时禁止扣费猜题。及时释放 Blob URL、事件、计时器。
3. Canvas 随容器宽度和旋转重绘，限制像素尺寸；捕获绘制失败，禁止用未模糊原图降级。
4. 精简手机页头占用，输入框字号至少 16px，触控按钮至少 44px；猜题候选列表可滚动。
5. 卡包列表同排按钮对齐且不挤出边界，保留此前修复。
验收：320/390/768/1920 宽度；挑战成功、失败重试、横竖切换；构建及服务端题库/图片回归。
