## 抽卡与卡库

用开瓦包现行 `PLAYER_CARDS` 与真实 `openPack` 连续模拟每种包 20,000 包：普通选手卡 538 张，金 98（18.2%）、银 155（28.8%）、铜 285（53.0%）。出金率含保底：试训包 4.84%、选拔包 8.60%、十连包 11.30%、各赛区包 8.60%。赛区库的金卡占比是中国 21/137（15.3%）、太平洋 24/133（18.0%）、美洲 30/146（20.5%）、EMEA 23/122（18.9%），而赛区包使用同一基础金卡率。可见卡库人数与掉率有意不同，并非逐人等权；卡包先抽金属档，再从该档均匀选卡。

噜噜卡调整前的普通选手池为 677 张，金 102（15.1%）、银 190（28.1%）、铜 385（56.9%）；全局包沿用开瓦包概率，但 LPL 与 LCK 金卡占比为 24.3% 与 28.7%，赛区包仍约 8.6% 出金。用户明确要求三区各自铜 > 银 > 金、金卡占比低于 20%，且 LCK > LPL > 其他；应先重标定卡库，再按新分布检查掉率，避免直接把金卡掉率升到卡库占比。

本轮落实后，噜噜卡普通选手池为金 81（12.0%）、银 196（29.0%）、铜 400（59.1%）。LPL 16/29/58、LCK 23/42/57、其他 42/125/285；全局三包和 LPL/LCK 包保留开瓦包的基础掉率。只有“其他包”按该区明显不同的卡库结构调整为基础金 5%、银 8%；实抽含保底约金 6.35%、银 28.84%、铜 64.72%。详见 [普通卡 v6 审查](card-rarity-rebalance-review.md)。
