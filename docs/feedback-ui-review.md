## 已实现

- 开包页提供快速模式开关，使用本地偏好保存，存储不可用时仍可开包。
- 快速模式直接展示普通卡；彩卡仍逐张展示独立特效，可立即继续。常规祭坛和翻卡流程保留；展示中的偏好切换从下一包开始生效。
- 全部揭晓后可继续下一包，沿用原支付方式，展示中文卡包名或金币消耗。包不足、金币不足或请求处理中禁用，不自动切换支付方式。
- 每次成功开包用递增序号重建展示，即使连续抽到同一卡牌也不会沿用上包翻牌状态。
- 开包与分解使用同步 ref 锁，避免同一帧双击重复提交；未知网络结果停止继续开包并提供刷新存档入口，不自动创建新的开包命令。
- 对账号请求补充未知结果判断：5xx JSON、200 空对象、非 JSON 响应均不能被当作明确失败或成功；仍保留原先同 requestId 的两次幂等尝试。未确认结果不吸收响应中的资产快照。
- 实际卡牌模式的 `LoLCatalog.tsx` 接入共用 `Dossier.tsx`，新增全部 114 张教练的搜索、赛区/稀有度筛选、分页及详情。教练展示战术、培养、激励、队伍及可核对的肖像来源。
- 保留原 LoL 图鉴的最近核对赛事、八项赛事统计、暂定评分说明和生日待补充提示；外部选手详情入口与返回行为保留。新增国籍、真名、队伍全名、卡牌 ID 搜索。
- 图鉴列表分页，每页最多 50 条；触摸控件至少 44px，窄屏允许筛选和分页换行。

## 前期定位纠正

最初策划审计到的 VLR/VAL 来源说明位于旧管理模式的 `Dossier.tsx`。线上卡牌模式实际引用 `LoLCatalog.tsx`，该页面原本已有 LoL 的赛事统计说明。它缺少教练分类，但不能声称线上原图鉴显示 VLR 残留。已在验收时追踪真实入口并合并共用实现，避免仅修改未被线上引用的页面。

真实入口接入已完成：`CardMode.tsx` → `LoLCatalog.tsx` → 共用 `Dossier.tsx`。玩家更新日志已新增 2026-09-22 条目，共 7 条，采用 DeepSeek 生成并审核的玩家文案。
