# 经济模拟落地决策报告

DeepSeek v4 pro 编写与模拟；Codex 审核。数据见 feedback-balance-audit.json。分析期望的单位为抽出的卡牌张数。

---

## 1. 决策表

| 项目 | 决策 | 理由 |
|---|---|---|
| 新硬保底 1200 | 已实现并通过边界测试 | 保留既有计数，所有支持彩卡的卡包共享最迟第1200张保底 |
| 旧 1201 替换 | 随 1200 集成 | 分析期望更优，仿真样本均值波动不采信 |
| 800 软保底 slope=5e-6 | 后续小幅试行候选（尚未实装） | 有效；本轮同步加小游戏奖励/商店折扣，需合并观测产出 |
| 800 软保底 slope=1e-5 | 候选，不先行 | 硬保底触发下降更明显；在合并奖励阶段不宜同时上 |
| 整体提高金银铜门槛 | 否决 | LEC/LCS/LCP/CBLOL 无金，回退铜破坏保底 |
| 分赛区硬配额/保金 | 不采用 | 尚未完成逐卡评分与存量迁移评审 |
| 长尾定向兑换/重复保护 | 后续讨论 | 当前受测包全部普卡可抽到，但只证明当前版本及受测包；不代表账号特例 |
| 全卡重写评分 | 不实施 | 需选手逐卡重评与迁移；本轮不启动重写计划 |
| 降低玩家既有卡 | 不实施 | 玩家卡身份、升级存量、市场已上架卡、杯赛报名快照均有迁移风险 |
| 小游戏奖励/商店折扣 | 本轮同步 | 属另一开发侧；不削挑战作为经济相互影响项 |
