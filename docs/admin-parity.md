# 后台功能对照

参考 Val_Manager（开瓦包）的 dashboard/site API，以及 val_player 的统计后台与 box 建议信箱。

| 来源功能 | 噜噜卡入口与实现 |
| --- | --- |
| 今日新增、活跃、会话与访问；14 天趋势 | 数据总览；北京时间按天统计，新增由首次事件日期计算 |
| D1 / D3 / D7 留存 | 数据总览；目标日完整结束后才显示结果 |
| 累计、设备平均/中位、设备日平均/中位时长 | 数据总览；累计心跳去重，跨日使用增量 |
| 设备类型、来源、页面、屏幕尺寸 | 数据总览；屏幕尺寸按设备最新记录分桶 |
| 前端异常、存储失败、持久化统计 | 数据总览；异常只记录类别和文件位置，不上传异常正文 |
| 7 / 30 / 90 天及自动刷新 | 数据总览；每 5 分钟刷新可见页面的实时汇总 |
| 卡包、收藏、挑战、比赛行为 | 游戏报表 |
| 生涯漏斗、角色、出身、年份、观看/跳过 | 保留于折叠的原版兼容报表；卡牌模式没有生涯事件，可能为空 |
| 建议热门、最新、我的、投票/取消 | 玩家信箱；内测提交即公开，无审核及小时/日额度 |
| 建议状态、置顶、删除、合并 | 建议管理；合并去重票数并保留作者原文回执 |
| 玩家详情、收藏、交易、关联账号、彩卡来源 | 玩家查询与发奖 |
| 金币/卡包/卡牌批量发放、CSV 与卡牌选择 | 玩家查询与发奖；进入奖励信箱，重复领取不重复结算 |
| 发放历史、重复发奖预览和处理 | 运营工具；修改前展示预览并二次确认 |
| 自动市场风控、手动封禁/解除、观察标记 | 交易风控与运营工具 |
| 手机审核、解除绑定、短信服务状态 | 账号审核与运营工具；Demo 默认不启用手机门槛 |
| 微信二维码与社区配置 | 社区配置 |
| 接口性能 | 数据总览的性能汇总 |

统计口径：新增/留存/时长等明细依赖仍保留的原始事件；清理原始事件后，明细不代表完整历史。持久化累计汇总单独展示。设备数指匿名浏览设备标识，不等同于真实人数。

建议仍有基础的正文长度、请求体和总存储容量保护；这些不是投稿审核或每日额度。后台保留旧 pending 状态的兼容能力，新投稿统一直接 shown。

验证：`check_dashboard.ts`、`check_admin_entry.mjs`、`check_admin_metrics.mjs`、`check_mailbox.ts`。集成测试使用独立内存数据库。
