# 全服杯推进超时恢复（2026-09-23）

全服杯原本把正在推进的一趟保存为单个 Promise。如果比赛计算线程或数据库等待一直不返回，后续每 2 秒的定时调用都复用同一个 Promise，赛事便可能永久停在当前轮。

现给每趟推进 120 秒上限。超时会拒绝本次调用并进入原有错误日志、释放单飞锁、重置比赛计算线程；下一次定时调用重新读取数据库中的赛程继续推进。测试可注入更短的上限。上限不是杀死数据库语句；若旧语句随后返回，旧版淘汰赛的轮次 CAS 只允许一趟写入，瑞士赛的比赛租约与短事务阻止旧计算覆盖新结果。启动、开奖和奖金仍沿用既有事务与唯一收据。

验收：`check_cup_clock.ts` 覆盖单飞、卡住释放、旧任务迟到、普通失败与定时器取消；`check_open_cup_worker.ts` 覆盖线程重置后重新计算；`check_open_cup.ts`、`check_open_cup_v2.ts`、`check_open_cup_archive.ts` 和 `check_open_cup_swiss.ts` 均通过。没有改每天各组 12:00/20:00 的赛程、杯赛规则或奖励。
