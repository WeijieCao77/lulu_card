# 玩家反馈更新验收（2026-09-22）

执行依据：`player-feedback-plan-2026-09-22.md`；用户补充小游戏缺乏动力、挑战最受欢迎。DeepSeek v4 pro 负责主要实现及返修，Codex 审查、整合、测试和发布。具体调用及拒收问题见各子项 review 文件，未将模型初稿直接发布。

## 本轮落地

- 快速开包可选并记住设备偏好，普通卡直接揭晓，彩卡保留独立特效；支持同支付方式继续下一包。未知网络结算先刷新核对，避免盲目再次扣款。
- 教练图鉴接入实际卡牌入口，可查询 114 张教练，分页每页 50 条；保留原 LoL 选手赛事统计。
- 六赛区每周自选一个八折赛区，2600→2080 金币，同周不可更换；北京时间周一重置。旧页面价格不一致拒绝交易并提示刷新。
- 补齐 6 位选手、5 位教练的本地 WebP 肖像，共 102700 字节；身份及来源逐一复核。仍缺 63 位选手与 43 位具名教练（另有 TBD），不宣称全量补齐。
- 修正彩卡硬保底边界：支持彩卡的普通包最迟第 1200 张触发，保留旧进度；概率实测移到 Worker，按需运行并缓存本页面结果。
- 小游戏金/银/铜分别 400/250/100 金币，金银另有位置包；每日首次金银额外选拔包，每天最多 1 个，仍共 5 次。挑战奖励、次数和入场费保持。
- 修复电脑天梯对手缺人、缺位置造成无法比赛：仅临时竞技场使用真实普通选手补位并标记“临时替补”，不改真实战队注册表、玩家卡牌或真人对战阵容。

## 数值决定

六赛区各 100002 张真实开包覆盖了全部 677 张基础选手卡，没有发现静态不可抽卡；这不排除特定账号问题。每区 100 个模拟账号的集齐中位数：LPL 4299 张、LCK 2574、LEC 693、LCS 636、LCP 579、CBLOL 693；LPL 的收集长尾明显。

直接将金卡门槛提高到 86 会使四个赛区没有金卡，故本轮不降级现有卡。800 抽软保底已完成模拟但未启用，避免和小游戏、折扣调整同时叠加；详见 `feedback-balance-decision.md` 与原始审计 JSON。模拟覆盖与集齐数字是调整前基线，不是新保底的玩家承诺。

- 构建及类型检查通过。
- 新增回归：硬保底边界、周选择与价格保护、10 类未知网络结果、小游戏 11 组奖励边界、全部电脑对手阵容。跨日、重复发奖、客户端伪造、旧存档均有检查。
- 101 支电脑队伍均实际完成 BO1；97 套杯赛阵容检查，已匹配 UP 的旧天梯对局及含 UP 的旧杯赛均完成真实动作结算；原队伍和选手表保持不变。
- 原有世界赛卡、战队继承、后台、信箱、市场、LoL 比赛与杯赛报名回归通过；挑战搜索 2016 项检查及三类题图资源投递检查通过。

- 320 像素下挑战模糊图片实际渲染、Faker 候选可见；未为测试消耗线上玩家资源。没有修改线上反馈内容、投票或状态。

开发中曾捕获 DeepSeek 的 Map 初始化错误，修正后重新完成全量对手测试与构建。开发热更新历史错误不应被描述为发布版故障；发布前以最终构建为准。

## 限制与后续

本轮没有实体 iOS Safari、Android Chrome、微信内置浏览器或 100 人并发压测结果，不能据此保证这些环境全部无故障。挑战继续作为重点体验；后续应结合玩家实际完成率、金币及卡包净产出评估软保底和收集长尾。未核实的肖像继续保留缺失，不用其他选手冒充。

发布以 Git 提交和 Railway 的对应构建、`/readyz` 与线上静态资源一致为准；本记录不将仅推送代码等同于部署成功。
