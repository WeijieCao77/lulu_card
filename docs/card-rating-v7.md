# 选手评分 v7（2026-09-26）

撸撸卡自己的评分模型，从英雄联盟经理复制后独立维护：`scripts/lol_rating/build_lol_ratings.py` 生成评分表 `scripts/lol_rating/ratings-2026.json`，`apply_lol_ratings.py` 写入 `src/data/world.json`。两个游戏互不影响。游戏内估算，不是官方排名。

## 相对 v6 的改动（站长定）

| 项目 | v6 | v7 |
|---|---|---|
| 数据年份 | 2024–2026（20/30/50%） | 2016–2026：2026 占 50%，其余 50% 按每早 2 年减半，只分给本人有比赛的年份 |
| 比赛分量 | 只算国内联赛，常规赛与季后赛同等 | 常规赛 ×1、季后赛 ×1.5（单独成组比较）、MSI ×2、世界赛 ×2.5（与同届同位置比较） |
| 关键局权重 | 6–9% | 减半，省下的按比例给其他七项 |
| 运营构成 | RAPM 40% / 队伍 20% / 资历 40% | 55% / 30% / 15% |
| 荣誉 | 无 | 世界赛冠军 +1、亚军 +0.5、MSI 冠军 +0.5，每早 4 年减半，封顶 +3 |
| 赛区基准 | 2024–26 国际赛 | 不变（反映现在的强弱）；补齐 2016 年起的旧联赛代码 |
| 卡面分档门槛 | LPL 76/79、LCK 70/80、其他 66/71 | 不变 |

各年权重：2016 0.7%，2017 0.9%，2018 1.3%，2019 1.9%，2020 2.7%，2021 3.8%，2022 5.3%，2023 7.6%，2024 10.7%，2025 15.1%，2026 50.0%

核对：复制过来的模型用 `--baseline`（原参数）运行，625 名有数据选手的来源分与八项属性与 v6 数据逐一相同。
