## 最终行为

- 卖卡可开启“只看重复卡”，包含普通重复卡与升级后的备用卡，不把同一选手不同版本当作同一卡。默认仍能出售唯一主卡。
- 挂牌等级沿用服务器托管顺序：普通重复卡 +0、最低等级备用卡、最后主卡；参考价也使用这个实际等级。
- 成交建议只取接口最新 8 笔中的同等级有效成交，优先近 7 天至少 3 笔，否则近 30 天至少 3 笔，使用中位数。样本不足不建议，不混用等级或全历史均价。建议遵守当前起拍底价与 50 万上限；点击仅填写起拍价，不提交挂牌、不改一口价。界面明确样本与参考性质，无法承诺成交价，也不构成反操纵保证。
- 历史请求有取消、序号、卡牌/等级作用域校验。换卡、关闭、重试时不沿用旧建议；点击时重新检查有效期。
- 可关注至多 50 张选手卡；本机存储以账号 ID 隔离，同账号标签页同步。存储不可写时保留本次页面清单并显示提示，不宣称跨设备同步。
- “只看关注”在服务端 SQL 分页前与现有搜索/稀有度/赛区等筛选相交。未提供关注字段保持原行为；空清单返回空货架。筛选菜单与统计池也按关注卡过滤，界面的“全站”张数继续明确表示全站总数。不会修改共享菜单缓存。
- 关注清单管理独立于在售结果，没有挂牌的卡也能取消关注；空清单与有关注但暂无挂牌使用不同提示。
